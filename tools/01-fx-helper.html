INDEX 01 自製開發 React 18 + TypeScript Hono Dual-Runtime Cheerio

外匯小幫手 — 匯率與手續費比較

以 React 18 與 Hono 建構的雙執行環境全端匯率試算系統，整合台灣主要銀行牌告爬蟲、Yahoo Finance 交叉匯率、海外刷卡淨回饋與 Multi-hop 多跳跨國匯款逆向成本演算法。

快取與解析套件 Cheerio + 5 分鐘 Map TTL

問題背景與架構解法

過去的痛點

海外留學或跨境消費時，銀行只提供單段牌告匯率，難以一次比較 JCB / Mastercard / VISA 加計 1.5% 海外手續費與各卡現金回饋後的淨損益，更難逆推「台幣 ➔ 美元/中轉行 ➔ 歐洲網銀」的多跳電匯總支出。

本工具的解法

由 Hono 後端統一聚合台灣銀行、玉山、國泰與國際交叉匯率，前端提供情境式逆算模型：只要輸入國外收款實領金額，系統自動加計電匯費、郵電費與中轉損耗，輸出各銀行與路徑的總台幣支出排行榜。

前後端架構與資料來源設計

  • 雙運行環境後端（api-hono.ts）：核心路由使用輕量級框架 Hono 撰寫，透過 functions/api/[[route]].ts 部署為 Cloudflare Pages Functions 邊緣服務，同時保留 server.ts（@hono/node-server）支援 Node.js 容器運行與 Vite 開發整合。
  • 三大即時匯率資料來源：
    • 臺灣銀行（BOT）：抓取 rate.bot.com.tw/xrt?Lang=zh-TW 並使用 cheerio 解析 HTML 表格中的現金／即期買賣價。
    • 玉山銀行與國泰世華銀行：直接對接銀行對外匯率查詢接口取得即時牌價。
    • Yahoo Finance API：透過 v8/finance/chart/{CURRENCY}TWD=X 等端點補足非台幣計價交叉匯率與歷史走勢圖表。
  • 5 分鐘記憶體 TTL 快取：後端建立 Map 快取（CACHE_TTL = 5 * 60 * 1000），防止短時間頻繁爬蟲觸發銀行限流（Rate Limit）。
  • 前端模組化元件（src/components/）：切分為 BankRatesBoard.tsx（即時看板排名）、CreditCardCompare.tsx（刷卡手續費與淨回饋試算）、FxCalculator.tsx（外匯兌換計算機），並於 App.tsx 實作 Multi-hop 多跳匯款路線排程與 JSON 匯入匯出。

核心演算法與計算公式解析

CORE ALGORITHMS · 逆算匯款成本與信用卡淨回饋邏輯 
[1] Multi-hop 逆向匯款總成本（目標實收金額 A_target）
    - 直匯成本   = ceil(A_target * Rate_spot_sell) + 匯出手續費(0.05%, NT$100~800) + 郵電費 + 全額到行中轉費
    - 多跳中轉   = (A_target / Rate_cross) -> 換算 USD 需求 -> 以銀行 USD 即期賣出價換回 TWD 成本
    - 實質匯率   = 總支出新台幣 / 實收外幣金額 A_target  ➔  依總支出由低至高自動排名

[2] 海外刷卡手續費與淨回饋（外幣消費 A_foreign）
    - 折合台幣   = A_foreign * Rate_network (VISA / Mastercard / JCB)
    - 海外手續費 = round(Base_TWD * 1.5%)
    - 信用卡回饋 = round(Base_TWD * R%)
    - 實際淨支出 = Base_TWD + Fee_TWD - Reward_TWD  (當 R% > 1.5% 即顯示淨倒賺比率)

工程與產品觀察

這份專案展現了極高的實用工程思維：前端用 TypeScript 嚴謹管理各幣別定義（currencies.ts）與邊緣 API 防呆（api.ts），後端用 Hono 同時兼容 Serverless 與傳統伺服器，解決的更是留學生與旅外族最容易被銀行隱藏手續費剝削的真實場景。
