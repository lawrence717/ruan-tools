極簡短網址服務（ruan.edu.kg）

將前後端 UI、轉址引擎與後台管理系統濃縮進單一 Cloudflare Worker 檔案的無伺服器短網址服務，搭配 KV 原生 TTL、非阻塞點擊分析與企業級登入資安防護。

運行架構 單檔 Cloudflare Worker
資料儲存層 Cloudflare KV（URL_KV）

問題背景與架構解法

過去的痛點

坊間免費短網址服務常安插廣告過渡頁、限制免費自訂短代碼（Custom Slug），且一旦服務商改制或收攤，過去印在海報或報告上的連結便集體失效。

本工具的解法

以零主機費用的 Cloudflare Workers + KV 建置在個人主網域下，享有全球邊緣節點毫秒級 302 轉址，並可自由管理自訂短碼、到期天數與點擊來源統計。

系統架構與核心設計亮點

  • KV 鍵值設計與 Metadata 列表加速：每筆短連結以 URL:<slug> 儲存完整 JSON（包含 longUrl、titleNote、clicks、countries、devices 與近 20 筆造訪紀錄），同時將摘要寫入 KV metadata，讓 /admin 後台列表不需逐筆讀取完整 Payload 即可快速渲染。
  • 原生 TTL 過期機制：支援選填「有效天數（ttlDays）」，後端自動換算為秒數傳入 KV 的 expirationTtl（最低 60 秒），時間一到由 Cloudflare 平台自動清理。
  • 防衝突與防無限迴圈保護：內建 RESERVED_SLUGS 系統保留字檢查（避免與 admin、api 等路徑撞名）、僅允許 http/https 協議，並禁止縮短本系統自身網域（url.origin）防止循環跳轉攻擊。
  • 雙重登入與資安防護：後台整合 timingSafeEqual 常數時間比對防範計時攻擊、crypto.subtle SHA-256 加鹽密碼雜湊、Cloudflare Turnstile 人機驗證、每 5 分鐘建立速率限制（RATE_LIMIT_SURL）、連續失敗 5 次鎖定 IP 15 分鐘，以及 HttpOnly; Secure; SameSite=Lax Session Cookie。

非同步零延遲轉址與統計流程

EDGE REDIRECT PIPELINE · 轉址零延遲統計架構 (ctx.waitUntil) 
GET /:slug
  ├─ 1. 檢查 RESERVED_SLUGS 並讀取 env.URL_KV.get("URL:" + slug)
  ├─ 2. 驗證目標網址協議合法性 (isValidHttpUrl)
  ├─ 3. 從 Cloudflare request.cf?.country 與 User-Agent 解析國家及裝置 (Desktop / Mobile / Tablet)
  ├─ 4. 呼叫 ctx.waitUntil(env.URL_KV.put(...)) 於背景非同步更新點擊統計
  └─ 5. 主執行緒無需等待資料庫寫入完成，立即回傳 HTTP 302 Redirect！

工程細節觀察

利用 Cloudflare Workers 專屬的 ctx.waitUntil() 把統計寫入放到背景執行，讓短網址轉址的回應延遲不會被 KV 寫入拖慢；搭配嚴格的 CSP 與 X-Frame-Options: DENY 標頭，單一檔案即達成高安全等級的個人數位基建。
